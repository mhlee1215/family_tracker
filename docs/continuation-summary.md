# Family Tracker Continuation Summary

Current scope: local web/PWA MVP for baby tracking.

## Product Goal

Reduce baby-log input fatigue by accepting ultra-short natural-language entries and filling missing context automatically while preserving which values were explicit, system-provided, inferred, or corrected.

## MVP Types

- Sleep
- Milk feeding
- Solid feeding
- Diaper

## Current Technical Direction

- Local web/PWA first.
- SQLite local storage.
- Provider abstraction from the start.
- Cloud accounts and sync later.
- Capacitor iOS/Android packaging after the web app and sync model are proven.
